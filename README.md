# Azure-AD
Azure AD Lab



Simple reason for this lab is for my documentation on using Azure and creating Vms "clients" can use to connect to a domain. Simple to navigate at first but find it slow on creating Vms as I was limited due to free 30* day trial. First issue I faced was limited azure vm type, you will need to change regions to get access to a decent vm as I choose D2s_v3 for both machines. Second hurdle I wanted to fix was the subnet they normally give out as it took me two recreations of this projects to noticed where to do that from. I found inbound rules pretty simple to use as I fixed RDP rule to allow only my IP to connect to the vms.
